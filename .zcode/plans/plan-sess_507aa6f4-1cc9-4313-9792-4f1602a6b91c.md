# AION Protocol — Phase 1 实施方案（按用户确认收紧）

## 范围

新增 sibling crate `crates/aion-protocol`。**纯协议数据层**——不包含 `Tool` trait、`ToolRegistry`、不依赖 `cordis`。`Tool` 契约与 `ToolRuntime` 调度留到 Phase 2 放进 services。

依赖只有三个：`serde + serde_json + thiserror`。零新重型依赖、不依赖 cordis、不依赖 aion-services。

## 设计决策

| # | 选择 |
|---|---|
| D1 | Phase 1 = 纯数据，无 Tool trait（→ Phase 2 在 services 做） |
| D2 | Tool 不接收 SecurityContext（Phase 2 Runtime 持有） |
| D3 | 不依赖 cordis |
| D4 | 不依赖 async-trait |
| D5 | 所有协议类型 `#[derive(Serialize,Deserialize)]` |
| D6 | JSON Schema 自手写枚举 + Document + validate |
| D7 | ID 类型 = 薄 wrapper + 进程唯一生成（pid+nanos+atomic counter） |

## 类型字段

- **JsonSchema** (snake_case tag): `Null | Bool | Integer{min,max} | Number{min,max} | String{min_len,max_len,pattern} | Array{items,min,max} | Object{props,required,additional} | OneOf(Vec<Var>) | Ref(String) | Any`; 外层 `JsonSchemaDocument { root, defs: BTreeMap<String, JsonSchema> }`
- **Risk** enum `Low|Medium|High|Critical` Copy/Eq/Hash, rename_all="lowercase"
- **ToolDefinition**: name, description, input: JsonSchemaDocument, output: Option<JsonSchemaDocument>, required_caps: Vec<String>, risk: Risk
- **ToolCall**: call_id, tool, arguments: Value, sandbox: Option<ToolSandboxHint> (Default|NoneExec|Strict)
- **ToolResult**: call_id, status, data: Value, artifacts: Vec<Artifact>, events: Vec<AionEvent>
- **ResultStatus** (tag): `Success | Error{kind:ErrorKind,message} | Pending{request_id,summary} | Denied{cap,hint}`; ErrorKind = `Internal|Timeout|InvalidInput|NotFound|ExternalService|Unavailable`
- **Artifact**: `Path{path,kind:PathKind,size} | Url{url,mime} | Blob{content_type,base64,byte_size}`
- **UIBlock** (tag): `Text{markdown} | Markdown{source} | Table{headers,rows} | Chart(Chart) | File{path,kind,size?,mime?} | Image{src,alt?,width?,height?} | Terminal{tool_call_id,kind:TerminalKind,max_lines?} | ProcessList{tool_call_id,max,filter?} | SystemStats{tool_call_id,kinds:Vec<StatKind>} | Confirmation(ConfirmationBlock)`
- **Chart**: `Line{title,x_label,y_label,series:Vec<ChartSeries>} | Bar{title,x_label,y_label,bars:Vec<ChartBar>} | Points{title,series:Vec<ChartSeries>}`; ChartSeries{name, points: Vec<ChartPoint>}; ChartPoint{x,y: f64}; ChartBar{label,value}
- **UIAction** (tag): `Invoke{tool,arguments,label} | Confirm{request_id,choice} | Cancel{request_id}`
- **ConfirmationBlock**: request_id, title, description, consequences: Vec<String>, options: Vec<ConfirmationOption{choice,label,description,style:ConfirmationStyle}>, default_choice; ConfirmationStyle = `Primary|Danger|Ghost`
- **Session**: id: SessionId, agent, created_at: u64, state: SessionState(Open|Closed), conversation, pending: HashMap<RequestId, StalledCall>
- **StalledCall**: tool, arguments, prompt, pending_since（Phase 2 Runtime 用）
- **Message**: id: MessageId, role: Role(User|Assistant|Tool|System), text: Option<String>, blocks, actions, tool_calls, timestamp
- **AionEvent**: id, session_id, kind: AionEventKind, timestamp, payload: Value
- **AionEventKind**: `SessionStarted|SessionEnded|ToolCallStarted|ToolCallFinished|ToolCallFailed|PermissionDenied|ConfirmationRequested|ConfirmationGiven`
- **ProtocolError** (thiserror): `UnknownTool|DuplicateName|SchemaMismatch{expected,got,path}|PermissionDenied{cap}|RequestNotFound|Io{path,source}|InvalidArguments`
- **SchemaError** (thiserror): `TypeMismatch{at,expected,got}|MissingProperty{name}|RequiredFieldMissing|NumberOutOfRange{at,got,min?,max?}|StringLength{at,got,min,max}|RefUnknown{name}`

ID 模板:
```rust
pub struct CallId(pub String);
impl CallId { pub fn new() -> Self { /* pid + nanos + atom */ } pub fn as_str(&self) -> &str { &self.0 } }
```
同类 SessionId/MessageId/RequestId。
